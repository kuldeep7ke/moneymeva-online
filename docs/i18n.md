# i18n System

## Languages

| Code | Name | Default |
|---|---|---|
| `mr` | मराठी (Marathi) | Yes |
| `hi` | हिन्दी (Hindi) | No |
| `en` | English | No |

## Files

- `src/lib/i18n/translations.ts` — all strings
- `src/lib/i18n/index.tsx` — I18nProvider + useTranslation hook

## Usage

```tsx
const { lang, setLang, t } = useTranslation();

t('nav.dashboard')              // "डॅशबोर्ड"
t('common.save')                // "सेव्ह करा"
t('tx.add', { title: 'खर्च' })  // "खर्च — नवीन"
```

## Philosophy

- Grammar stays native (Marathi/Hindi SOV structure)
- English loanwords for tech terms: Dashboard, Save, Sync, UPI, PIN
- Everyday words for money: खर्च, बचत, पैसे, रक्कम, तारीख
- No repetition — vary word choice across keys
- English footer always: `© 2026 Money Meva.`

## Adding a New Language

1. Add entry in `translations.ts`
2. Add language option in `LanguageSelector.tsx`
3. Add nav labels in `AGENTS.md`

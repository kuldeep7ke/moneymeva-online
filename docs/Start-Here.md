# 🚀 Start Here

Welcome to the **Money Meva** Obsidian vault.

## What is this?

A documentation vault for the Money Meva personal finance app. Everything you need to understand, build, and maintain the project.

## How to use

1. **Start at [[Home]]** — your dashboard
2. **Read [[File-Map]]** — find any file fast
3. **Check [[Active-Tasks]]** — what's in progress
4. **Use templates** — create notes consistently

## Vault Structure

```
docs/
├── Home.md              ← Dashboard (start here)
├── Start-Here.md        ← You are here
├── Active-Tasks.md      ← Current work
├── Bug-Tracker.md       ← Open bugs
├── templates/           ← Reusable note templates
├── dev/                 ← Daily dev logs
├── features/            ← Feature planning docs
├── bugs/                ← Bug investigation notes
├── archive/             ← Completed/old notes
└── *.md                 ← Reference docs
```

## Templates

Open command palette (`Ctrl+P`) → "Templater: Insert template" → pick:
- **Daily Dev Log** — session notes
- **Feature** — plan a new feature
- **Bug Report** — investigate a bug

## Tips

- Use `[[wikilinks]]` to connect notes
- Tag with `#money-meva`, `#bug`, `#feature`, `#done`
- Pin `Home` to your sidebar for quick access
